Floating Tools

Cara build APK:
1. Buka folder ini di Android Studio (versi terbaru).
2. Tunggu Gradle sync selesai.
3. Menu Build, lalu Build Bundle(s) / APK(s), lalu Build APK(s).
4. File APK ada di app/build/outputs/apk/debug/

Fitur: bubble melayang yang bisa digeser, panel berisi browser, penerjemah, kalkulator, dan catatan.
Aplikasi ini untuk membantu belajar. Patuhi aturan sekolah atau kampus saat ujian.
